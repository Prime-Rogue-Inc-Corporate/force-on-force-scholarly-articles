# force-on-force-scholarly-articles

Scholarly articles supporting Force on Force, with a review of each against the model and a queue of
recommendations for the model's builder.

| Path | What it holds |
|---|---|
| `INSTRUCTIONS.md` | The brief for the reviewing chat. Start here. |
| `papers/inbox/` | PDFs waiting to be read. Kevin drops them here. |
| `papers/` | PDFs that have been read, renamed `author-year-short-title.pdf`. |
| `reviews/` | One file per paper or topic: what it found and what that means for the model. |
| `RECOMMENDATIONS.md` | The queue the builder reads and answers. |
| `BIBLIOGRAPHY.md` | Everything read, and what is still wanted. |

Two chats use this repository. The **reviewer** reads papers and writes reviews and recommendations. The
**builder** writes the model, reads `RECOMMENDATIONS.md` at the start of each version and answers each entry.
Neither edits the other's lines.

The model: https://forceonforce.si
